# 📦 Parcel Cost Estimator

## 📌 Project Overview
The Parcel Cost Estimator is a simple web-based application developed using HTML, CSS, and JavaScript.

This project helps users calculate the estimated delivery cost of a parcel based on its weight and delivery type.

## 🎯 Objectives
- To calculate parcel delivery charges easily.
- To reduce manual calculation.
- To provide quick and accurate cost estimation.
- To understand the basics of HTML, CSS, and JavaScript.

## 🛠️ Technologies Used
- HTML – For creating the webpage structure.
- CSS – For designing and styling the webpage.
- JavaScript – For calculating parcel delivery charges.

## ⚙️ Features
- Enter sender name.
- Enter receiver name.
- Enter parcel weight.
- Select delivery type.
- Calculate total delivery cost.
- Display parcel cost details.

## 💰 Delivery Charges

| Delivery Type | Rate per KG | Delivery Charge |
|---|---:|---:|
| Standard | ₹40 | ₹20 |
| Express | ₹70 | ₹50 |
| Same Day | ₹100 | ₹100 |

## 🧮 Formula

Total Cost = (Parcel Weight × Rate per KG) + Delivery Charge

Example:

Weight = 5 KG

Delivery Type = Standard

Total Cost = (5 × 40) + 20

Total Cost = ₹220

## ▶️ How to Run the Project

1. Download or clone this repository.
2. Open the project folder.
3. Open the index.html file in any web browser.
4. Enter sender and receiver details.
5. Enter parcel weight.
6. Select the delivery type.
7. Click on Calculate Cost.
8. View the estimated parcel cost.
